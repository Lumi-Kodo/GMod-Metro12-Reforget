## О проекте

**GMod Metro12 Port** — современный порт старого Metro-интерфейса для Garry’s Mod.

[Оригинальный мод](https://github.com/samster395/GMOD-Menu) был создан более двенадцати лет назад и использовал устаревшие версии AngularJS, jQuery, Bootstrap и собственный старый файл `menuApp.js`. Этот порт сохраняет внешний вид классического плиточного меню, но работает поверх актуальной структуры главного меню Garry’s Mod.

Порт изменяет преимущественно визуальную часть главной страницы и не заменяет современную логику браузера серверов, дополнений, сохранений и остальных разделов игры.

## Установка

> [!IMPORTANT]
> Перед установкой полностью закрой Garry’s Mod.

1. Скачай последнюю версию мода в разделе [Releases](../../releases/latest).
2. Распакуй скачанный архив.
3. Скопируй папку в каталог:

```text
Steam/steamapps/common/GarrysMod/garrysmod/addons/
```

4. Запусти Garry’s Mod.

## Известные ограничения

- Обновления Garry’s Mod могут перезаписать изменённые файлы.
- После крупных обновлений игры может потребоваться новая версия патча.
- Интерфейс изменяет локальные файлы клиента и не устанавливается через Steam Workshop.
- Мод не является официальным продуктом Facepunch Studios.
